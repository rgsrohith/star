# ✦ S.T.A.R. — Sanitation Technology with Automated Regulation

> **Non-invasive, real-time health monitoring and smart sanitation powered by AI and embedded biosensors.**

---

## 📌 Overview

**S.T.A.R.** transforms everyday toilet infrastructure into an intelligent, non-invasive health diagnostic platform. By integrating embedded biosensors with deep learning models, S.T.A.R. continuously tracks key health indicators, alerts users to potential health risks, and maintains hygiene automatically through UVC sterilization.

---

## ✨ Key Features

* 📊 **Real-Time Biomarker Tracking:** Automated detection of pH, glucose, protein, ammonia, and ketone levels.
* 🤖 **AI Stool Classification:** Uses a Convolutional Neural Network (CNN) model to analyze types and identify early health risks.
* 💧 **Hydration Monitoring:** Continuous tracking with visual hydration ring metrics and alerts.
* 🛡️ **UVC Sterilization:** Automated UV-C cycle for self-cleaning sensors and surfaces post-use.
* 📖 **Health Diary & Trends:** Weekly trends, health scoring, and historical biomarker analysis.
* 👥 **Community & AI Assistant:** Interactive support and community discussion space.

---

## 🛠️ System Architecture & Tech Stack

* **Frontend:** HTML5, CSS3 (Theme Variables for Light/Dark Mode), Modern JavaScript (ES6+)
* **Typography & Styling:** Space Grotesk, DM Sans, CSS Grid & Flexbox
* **Microcontrollers & Hardware:** ESP32 / Arduino, Sensor Arrays, UVC Modules
* **AI Engine:** CNN Deep Learning Model (Stool & Biomarker Classification)
